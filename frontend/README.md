# CareerPath AI - Frontend

공공데이터 기반 개인 맞춤형 AI 취업 내비게이션 프론트엔드 웹 애플리케이션 (Next.js / React / TypeScript / Tailwind CSS)

## 주요 화면 구성 (UI Architecture)

1. **사용자 프로필 & 적성 분석 (`/profile`)**
   - 전공, 학력, 보유 기술, 희망 조건 및 고용24 직업심리검사 결과 입력/조회
2. **AI 직무 및 채용공고 탐색 (`/jobs`, `/recruitments`)**
   - 적성 적합도 & 현재 준비도 2-트랙 직무 추천
   - 고용24 채용공고 및 기업 매칭 사유 시각화
3. **Skill Gap 분석 & 대시보드 (`/skill-gap`)**
   - 채용공고 출현 빈도 vs 사용자 보유 역량 비교 차트
4. **취업 경로 & 주차별 Action Plan (`/roadmap`)**
   - 타임라인 기반 개인 맞춤형 취업 내비게이션 로드맵
5. **What-if 취업 시뮬레이션 (`/simulation`)**
   - 역량/자격증/프로젝트 추가 시 취업 준비도 변화 시뮬레이터
6. **노동시장 분석 인사이트 (`/market`)**
   - 직무별 요구 역량 통계 및 트렌드
7. **AI 취업 전략 보고서 (`/report`)**
   - 8대 핵심 섹션으로 구성된 통합 AI Career Report
8. **대화형 AI Career Agent 채팅 (`/chat`)**
   - 조건 변경에 따른 동적 경로 재설계 챗봇 인터페이스

## 로컬 실행 방법

```bash
cd frontend
npm install
npm run dev
# 브라우저에서 http://localhost:3000 접속
```
